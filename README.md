# Aggiemon

Aggiemon is a turn-based RPG set at UC Daniel. Fight turkeys, gain skills, and level up.

This repository contains an alpha build of the project. The core gameplay systems have been implemented and are functional, while additional content and polish remain in development.

## Project Information
* This repo is a clone of the original which can be found here: https://github.com/DrewCoding/179-Final-Project
* More information on contributions and project details can be found in [AggieProjectDocument.md](https://github.com/POmolewa1/Aggiemon_alpha/blob/main/AggieProjectDocument.md).

## My Contributions 
My primary contributions focused on gameplay programming and game systems, including:

* Battle and encounter management
* Enemy AI behaviors
* Character and skill architecture
* Combat UI logic
* Player progression and level scaling
* Enemy spawning and respawn systems
* Basic Skill template and skill design

For a detailed breakdown of these systems, see [AggieProjectDocument.md](https://github.com/POmolewa1/Aggiemon_alpha/blob/main/AggieProjectDocument.md).
